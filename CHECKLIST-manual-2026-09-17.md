# Ручная проверка Ratatosk-desktop

Дата: 17 сентября 2026. Состояние: этапы 1–9 плана сделаны.

Автоматически проверяется 69 тестами (`./gradlew :app:test`) и сборкой `.deb`.
Здесь — то, что тесты проверить не могут: настоящее ядро, настоящая сеть,
настоящий телефон и глаза человека.

## 0. Перед началом

* `./gradlew :app:test` — зелёные, один тест пропущен (связка ключей, нужен
  `-Pratatosk.test.keyring=true`).
* `./gradlew packageDeb` — пакет собрался; `dpkg-deb -x` и запуск
  `opt/ratatosk/bin/Ratatosk` работают без `jna.library.path`.
* `.msi` собирается **только на Windows**: на Linux задача молча пропускается.

## 1. Аккаунты

- [ ] Создать аккаунт без PIN — обязательное предупреждение ядра до создания.
- [ ] Создать аккаунт с PIN; ярлык оставить пустым — он должен взять имя.
- [ ] Создать аккаунт с привязкой к компьютеру (флажок) — предупреждение о том,
      что потеря связки ключей равна потере переписки.
- [ ] Выйти и войти снова: аккаунт без PIN и привязанный — открываются сразу,
      без поля; аккаунт с PIN — спрашивает PIN, с индикатором на время счёта.
- [ ] Неверный PIN — понятная ошибка, а не английское «Failed to…».
- [ ] Скрытый аккаунт: неверный PIN — сообщение внутри диалога; верный —
      открывает без повторного вопроса.
- [ ] Удалить аккаунт с экрана выбора: подтверждение говорит, что вернуть
      переписку нельзя; после удаления его нет в списке, каталог аккаунта пуст,
      секрет устройства из связки ключей исчез.
- [ ] Войти другим аккаунтом: нет чужих чатов, групп, отпечатка и onion-адреса.

## 2. Переписка (полный клиент)

- [ ] Отправка по Enter и по Ctrl+Enter (переключатель в настройках).
- [ ] Ответ, правка своего сообщения, удаление у себя, отзыв у всех —
      с текстами ядра перед действием.
- [ ] Реакция и её снятие; чипы под сообщением.
- [ ] Пересылка в группу и в личный чат.
- [ ] Поиск по чату, переход к найденному старому сообщению (догрузка).
- [ ] Щелчок по цитате — переход к исходному сообщению с подсветкой.
- [ ] «Прочитано» у собеседника появляется, когда чат открыт и окно в фокусе,
      и не появляется, когда окно свёрнуто.
- [ ] Drag&drop файла в окно; Ctrl+V снимка экрана; выделение текста мышью.
- [ ] Правый щелчок по сообщению и кнопки при наведении.

## 3. Вложения

- [ ] Принять большой файл, остановить на середине, закрыть и открыть чат:
      «Остановлено на N%» и кнопка продолжения; продолжение идёт с того же места.
- [ ] После приёма кнопки «Открыть» и «Сохранить» появляются сами, без
      повторного входа в чат.
- [ ] Картинка открывается своим окном: колесо — масштаб, перетаскивание —
      сдвиг, двойной щелчок — сброс, Esc — закрыть; увеличенная картинка
      не наезжает на кнопки.
- [ ] Видео и звук открываются системным проигрывателем.
- [ ] Исполняемый файл (`.sh`, `.exe`) не открывается, а показывается в папке.
- [ ] Файл с именем `../../x` сохраняется в каталог загрузок, а не выше.
- [ ] Очистка потерянных файлов сообщает файлы, фрагменты и объём.

## 4. Группы

- [ ] Создать группу (текст ядра до создания, счётчик символов).
- [ ] Пригласить, исключить, выйти — каждый раз с текстом ядра.
- [ ] Картинку группы меняет только тот, кто ей распоряжается.
- [ ] Покинутая группа осталась в списке с пометкой «вы вышли», поле ввода
      заменено плашкой.
- [ ] Автор сообщения в группе: имя и лицо; щелчок по имени открывает карточку,
      а для незнакомца — честная карточка «нет в контактах».

## 5. Режим компаньона (нужен телефон)

- [ ] Привязка по ссылке: флажок Tor на виду, порт и адрес телефона — под
      «Дополнительно»; порт проверяется.
- [ ] До связи — полоса «Подключаемся к телефону…»; щелчок по ней показывает
      порт и ключ этого экрана, их можно ввести на телефоне руками.
- [ ] Данные из кэша помечены полосой «данные с прошлого подключения», пометка
      исчезает сама, когда телефон ответил.
- [ ] Профиль: фото видно и меняется, новое уходит на телефон; имя не правится
      (его задаёт телефон), ключей и ссылки нет.
- [ ] Карточка контакта: крупное фото и имя, без обещаний о сверке.
- [ ] Вложение с телефона: доля растёт от нуля, файл открывается, размер совпадает.
- [ ] Выключить в сеть телефон посреди приёма — «Ждём связи с телефоном»,
      после возврата приём продолжается с того же места.
- [ ] Переключатель копии переписки: включение спрашивает подтверждение с
      текстом о том, от чего шифрование не защищает; выключение стирает файл
      (`~/.ratatosk/companions/<id>.db`).
- [ ] Отзыв сопряжения с телефона — окно говорит об этом словами.

## 6. Транспорты и настройки

- [ ] Включение видимости в локальной сети — с предупреждением ядра.
- [ ] Tor: полоса подъёма в списке и в чате; после подъёма — onion в профиле.
- [ ] Почта: форма открывается заполненной, порты проверяются, видна
      заполненность ящика; «Изменить ящик» не затирает настройки пустыми полями.
- [ ] Yggdrasil: три режима, ключ (в том числе «взять у yggdrasilctl»), пиры,
      живой статус; адрес в меше виден в профиле.
- [ ] Nostr: npub, реле с автоподстановкой `wss://`, счётчик живых.
- [ ] Bluetooth: раздел виден только когда ядро говорит, что радио есть.
- [ ] Смена сети при открытом приложении (Wi-Fi, VPN) — связь восстанавливается
      сама, без перезапуска.

## 7. Прочее

- [ ] Резервная копия: экспорт с фразой, ключ восстановления, импорт на экране
      выбора аккаунта; ошибка не оставляет диалог заблокированным.
- [ ] Уведомления: приходят на входящие, не приходят для открытого и видимого
      чата, щелчок открывает нужный чат; трей прячет и показывает окно.
- [ ] Фон чата: установить, сменить, удалить; прозрачность пишется по
      отпусканию ползунка.
- [ ] Запуск с `LANG=en_US.UTF-8` — интерфейс по-английски, ничего не поехало.
- [ ] Узкое окно (меньше 720dp): одна панель за раз, «назад» по Esc, Alt+←
      и боковой кнопкой мыши.
